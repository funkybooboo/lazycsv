# plans

Project roadmap tracking feature development milestones and task completion status. This directory contains the strategic planning documents that guide the evolution of LazyCSV.

## Structure

- **[roadmap.md](roadmap.md)** - Main roadmap with version overview, guiding principles, and quick reference
- **[versions/](versions/)** - Detailed documentation for each version milestone (47 versions from v0.1.0 to v1.0.0)

## Navigation

The roadmap is organized into two parts:

1. **Main Roadmap** (`roadmap.md`) - High-level overview with:
   - Version table showing all milestones
   - Brief summaries (2-3 sentences) for each version
   - Guiding principles
   - Modal editing reference
   - Command and keybinding quick reference

2. **Version Details** (`versions/`) - Individual files for each version containing:
   - Complete feature lists and task breakdowns
   - Implementation details and architecture decisions
   - Test requirements and success criteria
   - Navigation links to previous/next versions

Each version file includes navigation links to move between versions sequentially and back to the main roadmap.
