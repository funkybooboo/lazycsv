**Already implemented in v0.25.0:**

- [x] `:copy` — copy current document as CSV to system clipboard
- [x] `:paste` — paste CSV/TSV from system clipboard, auto-detect delimiter
- [x] `-C` CLI flag — copy CSV output to system clipboard (non-interactive)
- [x] `-P` CLI flag — open CSV data from system clipboard in TUI
- [x] Auto delimiter detection (tab, pipe, semicolon, comma)
- [x] Platform support: macOS (pbcopy/pbpaste), Linux (xclip/xsel), Windows (clip/powershell)

**Deferred:**
- `"+yy` vim register syntax — `:copy`/`:paste` covers the same use case
