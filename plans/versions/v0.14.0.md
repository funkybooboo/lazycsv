**Features:**

**Keybindings:**
- [x] `~` - Toggle case (UPPER ↔ lower)
- [x] `g~` - Title Case cell
- [x] `g.` - Toggle boolean (true↔false, yes↔no, 1↔0, on↔off, y↔n)
- [x] `gj` - Swap current row with row below
- [x] `gk` - Swap current row with row above

**Commands:**
- [x] `:upper` / `:uppercase` - Uppercase current cell
- [x] `:lower` / `:lowercase` - Lowercase current cell
- [x] `:title` / `:titlecase` - Title Case current cell
- [x] `:trim` - Trim whitespace from current cell

**All transforms are undoable with `u`.**

**Implementation:**
- [x] src/transforms/mod.rs (new) — pure transform functions with 21 unit tests
- [x] src/csv/document.rs — `swap_rows()` method
- [x] src/history/mod.rs — `SwapRows` variant for undo
- [x] src/input/normal_mode/handler.rs — `~` keybinding
- [x] src/input/normal_mode/multi_key.rs — `g~`, `g.`, `gj`, `gk` keybindings
- [x] src/input/command_mode/executor.rs — `:upper`, `:lower`, `:title`, `:trim` commands
