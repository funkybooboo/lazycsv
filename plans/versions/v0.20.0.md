**Features:**

**Column Statistics:**
- [ ] :stats A - Show statistics for column A (sum, avg, min, max, count)
- [ ] :sum A - Show sum of column A
- [ ] :avg A - Show average of column A
- [ ] :count A - Count non-empty cells in column A
- [ ] :distinct A - Count distinct values in column A
