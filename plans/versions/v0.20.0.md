## Column Statistics Commands

Status bar commands for quick column analysis. Column specifiers accept header names (case-insensitive), 1-based numbers, or Excel letters (A, B, AA).

- [x] `:stats A` - Show all statistics for column A (sum, avg, min, max, count, distinct)
- [x] `:sum A` - Show sum of column A
- [x] `:avg A` / `:average A` - Show average of column A
- [x] `:count A` - Count non-empty cells in column A
- [x] `:distinct A` - Count distinct values in column A

## Excel-like Cell Formulas

Cells can contain formulas starting with `=`. The cell displays the computed result; the formula bar (title bar) and edit mode show the formula text. Formulas auto re-evaluate when referenced cells change. On CSV save, the computed value is written — formulas are a TUI-only feature lost on re-open.

### Supported Functions (24 total, all case-insensitive)

**Aggregate:**
- [x] `=SUM(A1:A5)` / `=SUM(A1,A3,A5)` - Sum of values
- [x] `=AVERAGE(A1:A5)` / `=AVG(A1:A5)` - Arithmetic mean
- [x] `=MIN(A1:A5)` - Smallest value
- [x] `=MAX(A1:A5)` - Largest value
- [x] `=COUNT(A1:A5)` - Count non-empty cells

**Math:**
- [x] `=POWER(A1, 2)` - Raise to power
- [x] `=CEILING(A1, 5)` - Round up to nearest multiple
- [x] `=FLOOR(A1, 5)` - Round down to nearest multiple

**Text:**
- [x] `=CONCAT(A1, " ", B1)` / `=CONCATENATE(...)` - Join text strings
- [x] `=TRIM(A1)` - Remove extra spaces
- [x] `=UPPER(A1)` - Convert to uppercase
- [x] `=LOWER(A1)` - Convert to lowercase
- [x] `=PROPER(A1)` - Capitalize each word
- [x] `=LEFT(A1, 3)` - Extract left characters
- [x] `=RIGHT(A1, 3)` - Extract right characters
- [x] `=MID(A1, 2, 3)` - Extract middle characters
- [x] `=SUBSTITUTE(A1, "Old", "New")` - Replace text by content
- [x] `=REPLACE(A1, 2, 3, "XYZ")` - Replace text by position

**Date:**
- [x] `=NOW()` - Current date and time
- [x] `=TODAY()` - Current date
- [x] `=DATEDIF(A1, B1, "d")` - Date difference (d=days, m=months, y=years)

**Lookup:**
- [x] `=VLOOKUP(value, A1:C10, 3, FALSE)` - Vertical lookup
- [x] `=HLOOKUP(value, A1:C10, 2, FALSE)` - Horizontal lookup

**Logic:**
- [x] `=IF(A1>10, "High", "Low")` - Conditional value (supports >, <, >=, <=, =, <>, !=)

### Formula System Features

- [x] Formula bar shows formula text when navigating to formula cells
- [x] Edit mode shows formula text (not computed value)
- [x] Auto re-evaluation when referenced cells change
- [x] CSV save writes computed values (formulas lost on re-open)
- [x] Formula completion popup on `=` in insert mode (filter-as-you-type, arrow nav, Enter/Tab to accept)
- [x] Formulas cleared on file switch and structural changes (row/column insert/delete)
- [x] Range references (`A1:B5`) and comma-separated references (`A1,A3,A5`)
- [x] Supports quoted string literals (`"text"`), numeric literals, and boolean literals in arguments

**Aggregation:**
- [x] Visual mode selection statistics
- [x] Footer row showing column totals (optional)
- [x] Statistics overlay/popup
