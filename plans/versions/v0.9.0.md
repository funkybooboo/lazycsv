**Features:**

**Config File Support:**
- [x] Load config from ~/.config/lazycsv/config.toml
- [x] Per-directory config (.lazycsv.toml)
- [x] Default settings (delimiter, encoding, zebra_striping, max_column_width, undo_limit)
- [x] Color customization (cursor, selection, search, zebra, header_bg, dirty_indicator)
- [ ] Keybinding remapping (advanced — deferred to future version)

**Config Options:**
```toml
[defaults]
delimiter = ","
encoding = "utf-8"
zebra_striping = true
max_column_width = 100
undo_limit = 1000

[theme]
zebra_bg = "#1e1e1e"
cursor_bg = "white"
cursor_fg = "black"
selection_bg = "darkgray"
selection_fg = "yellow"
search_match_bg = "yellow"
search_match_fg = "black"
header_bold = true
header_bg = "#333333"
dirty_indicator_fg = "red"

[sql]
format_uppercase = true
```
