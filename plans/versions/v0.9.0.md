**Features:**

**Config File Support:**
- [ ] Load config from ~/.config/lazycsv/config.toml
- [ ] Per-directory config (./.lazycsv/config.toml)
- [ ] Default settings (delimiter, undo_limit)
- [ ] Color customization
- [ ] Keybinding remapping (advanced)

**Config Options:**
```toml
[defaults]
delimiter = ","
undo_limit = 1000

[colors]
header_bg = "blue"
cursor_fg = "yellow"
dirty_indicator = "red"

[keybindings]
quit = ":q"
save_all = ":w"
```
