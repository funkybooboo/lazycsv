**Philosophy:**
Extend LazyCSV beyond CSV-only to support Excel and OpenDocument spreadsheet files natively. Spreadsheets are opened as in-memory documents, converted to CSV on save. Formulas are preserved in the formula bar for editing.

**Features:**

**TUI Support:**
- [x] Open .xlsx/.xls/.ods files directly in the TUI
- [x] Default to first sheet when no sheet specified
- [x] Select sheet by name or 1-based index as positional arg (e.g., `lazycsv file.xlsx 2`)
- [x] File marked dirty on open (CSV hasn't been saved yet)
- [x] Filename set to `{sheet_name}.csv` for save target
- [x] Directory scanner and file browser include .xlsx/.xls/.ods files (case-insensitive)

**Formula Support:**
- [x] Excel formulas stored in FormulaStore (separate from cell values)
- [x] Cell grid shows computed values (not formula text)
- [x] Formula bar (title bar) shows formula when cell is selected
- [x] Insert mode shows formula for editing
- [x] Unsupported formulas preserved with placeholder for display
- [x] DATE/TIME formulas show formatted dates (e.g., `8/8/2025 2:30 PM`)
- [x] DateTime cells formatted with locale-style date/time display

**CLI Extraction (`-x` flag):**
- [x] `lazycsv file.xlsx -x` extracts all sheets to `{filename}/` directory
- [x] `lazycsv file.xlsx 2 -x` extracts specific sheet by index
- [x] `lazycsv file.xlsx "Sheet Name" -x` extracts specific sheet by name
- [x] `-o` flag: directory (output to dir), file (single sheet), bare `-o` (stdout for piping)
- [x] Error when outputting multiple sheets to a single file
- [x] Summary output showing sheet names, row counts, and output paths

**SQL Query Support:**
- [x] `lazycsv file.xlsx -q "SELECT * FROM Sheet1"` queries xlsx/ods directly
- [x] `lazycsv file.xlsx 2 -q "SELECT * FROM Sheet2"` queries specific sheet
- [x] All sheets extracted to temp CSVs, loaded into SQLite, cleaned up after query

**Clipboard Copy (`-C` / `--cb-copy` flag):**
- [x] `lazycsv data.csv -C` copies CSV file contents to system clipboard
- [x] `lazycsv file.xlsx -C` copies spreadsheet sheet to clipboard
- [x] `lazycsv file.csv -q "SELECT ..." -C` copies query results to clipboard (also prints to stdout)
- [x] Streaming copy for large CSV files (no full file buffering in memory)
- [x] Cross-platform: pbcopy (macOS), xclip/xsel/wl-copy (Linux)

**Clipboard Paste (`-P` / `--cb-paste` flag):**
- [x] `lazycsv -P` writes clipboard CSV to `./clipboard.csv`
- [x] `lazycsv -P -o output.csv` writes clipboard CSV to specified path
- [x] Cross-platform: pbpaste (macOS), xclip/xsel/wl-paste (Linux)

**Split (`-S` / `--split` flag):**
- [x] `lazycsv data.csv -S 1000` splits into files of 1000 rows each (0.csv, 1.csv, ...)
- [x] `lazycsv data.csv -S 500 -o chunks/` splits into custom output directory
- [x] Works with CSV, XLSX, XLS, ODS files
- [x] Each output file includes the header row
- [x] Files numbered starting from 0
- [x] Streaming split for CSV files (never loads entire file into memory)

**SQL DML Support:**
- [x] INSERT, UPDATE, DELETE, ALTER statements in the TUI SQL editor
- [x] Current document synced to SQLite before DML execution
- [x] SELECT * after DML to refresh document in-place (no new output file)
- [x] Document marked dirty after successful DML
- [x] DML-aware IntelliSense: UPDATE/INSERT INTO/DELETE FROM → current table name only
- [x] SET context → column names from current document
- [x] WHERE context after SET → column names and functions
- [x] SELECT queries continue showing all available table names

**UI Enhancements:**
- [x] Zebra striping on alternating rows for readability (theme-based color)

**Terminal Robustness:**
- [x] Broken pipe handled gracefully (no error on `lazycsv -q ... | head`)
- [x] Terminal raw mode always restored on error/exit paths
- [x] Clear error message for piped stdin in TUI mode
- [x] Cursor visibility restored on TUI exit

**New Files:**
- `src/csv/xlsx.rs` — calamine-based xlsx/ods loading, formula extraction, sheet discovery
- `tests/dml_test.rs` — integration tests for SQL DML operations

**Dependencies Added:**
- `calamine` (v0.34) with `dates` feature for chrono-based DateTime formatting
- `rayon` (v1.10) for parallel sort
