**Focus:** Read and convert Excel spreadsheet files
**Tests:** TBD

**Philosophy:**
Extend LazyCSV beyond CSV-only to support Excel files natively. Spreadsheets are opened as in-memory documents, converted to CSV on save. Formulas are preserved in the formula bar for editing.

**Features:**

**TUI Support:**
- [x] Open .xlsx/.xls files directly in the TUI
- [x] Default to first sheet when no sheet specified
- [x] Select sheet by name or 1-based index as positional arg (e.g., `lazycsv file.xlsx 2`)
- [x] File marked dirty on open (CSV hasn't been saved yet)
- [x] Filename set to `{sheet_name}.csv` for save target
- [x] Directory scanner and file browser include .xlsx/.xls files (case-insensitive)

**Formula Support:**
- [x] Excel formulas stored in FormulaStore (separate from cell values)
- [x] Cell grid shows computed values (not formula text)
- [x] Formula bar (title bar) shows formula when cell is selected
- [x] Insert mode shows formula for editing
- [x] Unsupported formulas preserved with placeholder for display
- [x] DATE/TIME formulas show formatted dates (e.g., `8/8/2025 2:30 PM`)
- [x] DateTime cells formatted with locale-style date/time display

**CLI Extraction (`-x` flag):**
- [x] `lazycsv file.xlsx -x` extracts all sheets to `{filename}/` directory
- [x] `lazycsv file.xlsx 2 -x` extracts specific sheet by index
- [x] `lazycsv file.xlsx "Sheet Name" -x` extracts specific sheet by name
- [x] `-o` flag overrides output directory
- [x] Summary output showing sheet names, row counts, and output paths

**SQL Query Support:**
- [x] `lazycsv file.xlsx -q "SELECT * FROM Sheet1"` queries xlsx directly
- [x] `lazycsv file.xlsx 2 -q "SELECT * FROM Sheet2"` queries specific sheet
- [x] All sheets extracted to temp CSVs, loaded into SQLite, cleaned up after query

**New Files:**
- `src/csv/xlsx.rs` — calamine-based xlsx loading, formula extraction, sheet discovery

**Dependencies Added:**
- `calamine` (v0.34) with `dates` feature for chrono-based DateTime formatting
- `rayon` (v1.10) for parallel sort
