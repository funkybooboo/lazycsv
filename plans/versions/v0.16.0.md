**Features:**

**Find and Replace:**
- [x] `s/old/new/` — replace first occurrence in current cell
- [x] `s/old/new/g` — replace all occurrences in current cell
- [x] `%s/old/new/g` — replace all occurrences in all data cells
- [x] `5,10s/old/new/g` — replace in row range
- [x] `B,Ds/old/new/g` — replace in column range
- [x] `.s/old/new/g` — replace in current cell (dot prefix)
- [x] Regex patterns supported
- [x] `i` flag for case-insensitive matching
- [x] `g` flag for global (all occurrences)
- [x] Alternate delimiters (`s|old|new|g`)
- [x] Empty replacement for deletion (`s/old//g`)
- [x] All substitutions undoable with `u`
- [x] Status message shows replacement count

**Bulk Delete/Clear (already implemented):**
- [x] `:%d` — delete all data rows
- [x] `:B,Dd` — delete column range

**Implementation:**
- [x] src/input/command_mode/substitute.rs (new) — parser + executor with 15 unit tests
- [x] Wired before range_commands in executor to avoid %s/%d conflict
- [x] Compound undo for multi-cell substitutions

**Tests:**

- parse_substitute (7): basic, global, case_insensitive, no trailing delim, empty replacement, escaped delimiter, alternate delimiter
- parse_range (6): percent, current, dot, row, column, not_substitute

Integration tests (tests/substitute_test.rs — 17):
