## TUI Commands

- [x] `:export json [file]` — Export to JSON (array of objects, type-preserving)
- [x] `:export tsv [file]` — Export to TSV (tab-delimited with escaping)
- [x] `:export md [file]` — Export to Markdown table (GFM)
- [x] `:export xlsx [file]` — Export to XLSX spreadsheet (numeric cells stored as numbers)
- [x] `:export parquet [file]` — Export to Parquet (via DuckDB)
- [x] Auto filename: `:export json` on `data.csv` → `data.json`
- [x] Visual selection export (export only selected cells)

## CLI `-o` Format Detection

- [x] `-o output.json` / `-o output.xlsx` / `-o output.parquet` — auto-detect format from extension
- [x] Works with `-q` query mode, `-s` sort mode, `-D` dedup mode

## Implementation

**New module:** `src/export/`
- `src/export/mod.rs` — `ExportFormat` enum, dispatch, `collect_document_data`
- `src/export/json.rs` — JSON array of objects via `serde_json`
- `src/export/tsv.rs` — Tab-separated with escape sequences
- `src/export/markdown.rs` — GFM table with pipe escaping
- `src/export/xlsx.rs` — XLSX via `rust_xlsxwriter`, bold headers, numeric detection
- Parquet via DuckDB COPY (temp CSV → DuckDB → Parquet)

**Modified files:**
- `Cargo.toml` — added `rust_xlsxwriter = "0.94"`
- `src/lib.rs` — added `pub mod export`
- `src/input/command_mode/executor.rs` — added `:export` command with visual selection support
- `src/main.rs` — `-o` extension-based format detection in query, sort, dedup modes
- `src/ui/help.rs` — documented `:export` command
