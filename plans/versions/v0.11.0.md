**Philosophy:**
Bring the same powerful vim editing experience from Magnifier mode to the SQL editor. Users should be able to edit SQL queries with full vim modal editing, just like editing cell content. Maximum code reuse from Magnifier mode.

**Features:**
- [X] Modal editing in SQL editor (Normal, Insert, Visual modes)
- [X] All vim navigation commands (hjkl, w, b, e, 0, $, gg, G, etc.)
- [X] All vim editing commands (x, dd, yy, p, etc.)
- [X] Visual mode selection and operations (v, V, y, d)
- [X] Search within SQL query (n, N, *)
- [X] Undo/redo within SQL editor (u, Ctrl+r)
- [X] Multi-line SQL query editing with proper cursor navigation
- [X] Line numbers in SQL editor
- [ ] Syntax highlighting for SQL keywords (deferred to future version)

**Code Reuse Strategy:**
- [X] Extract shared vim editor logic from Magnifier mode (src/magnifier/)
- [X] Create src/vim_editor/ module with reusable components:
  - [X] VimEditor struct (cursor, content, mode, selection, undo_stack)
  - [X] handle_key() method for KeyEvent processing
  - [X] Motion commands module (hjkl, w/b/e, 0/$, gg/G, etc.)
  - [X] Operator commands module (x, dd, yy, p, etc.)
  - [X] Visual mode module (v, V, selection logic)
  - [X] Search module (/, n, N, *)
  - [X] Undo/redo module
  - [X] Ex commands module (:w, :q, :wq, :noh)
- [X] Refactor Magnifier mode to use new vim_editor module (479 lines, down from 2,101 lines - 77% reduction)
- [X] Adapt SQL editor to use vim_editor module
- [X] Both Magnifier and SQL editor share 90%+ of editing logic via VimEditor

**Key Differences from Magnifier:**
- SQL editor executes query on Ctrl+Enter or :w/:wq
- SQL editor exits on Esc (in Normal mode) or :q
- Magnifier saves to cell and navigates with Alt+hjkl, SQL editor doesn't navigate
