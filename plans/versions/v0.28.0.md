## Summary

Native Parquet, JSON/NDJSON, and SQLite file support across all modes — TUI viewing, SQL queries, CLI counting/headers, clipboard copy, and file splitting. DuckDB serves as the universal reader with zero new crate dependencies. Parallel row counting with rayon for large CSV files. Clipboard paste auto-detects JSON vs CSV content. Improved piped-stdin detection prevents TUI hangs.

## Features

### Multi-Format File Support

- **Parquet** (`.parquet`) — open in TUI, query with `-q`, count with `-r`/`-c`, headers with `-h`
- **JSON** (`.json`) — array-of-objects format, auto-detected by DuckDB
- **NDJSON** (`.ndjson`, `.jsonl`) — newline-delimited JSON
- **SQLite** (`.db`, `.sqlite`, `.sqlite3`) — with table selection via second positional arg
  - `lazycsv file.db` — loads first table
  - `lazycsv file.db tablename` — loads specific table
  - Table selection reuses the XLSX sheet specifier mechanism

### Architecture

- New module: `src/csv/foreign_formats.rs`
  - `foreign_format_type(path)` — detect format by extension
  - `load_foreign_format(path, table)` — load any format via DuckDB into `Vec<Vec<String>>`
  - `duckdb_reader_sql(path, table, hint)` — generate DuckDB VIEW SQL for query mode
  - `get_sqlite_tables(path)` — list tables in a SQLite database
- All new formats route through `RowStorage::in_memory()` (same as XLSX pattern)
- Query mode uses DuckDB native readers: `read_parquet()`, `read_json()`, `read_ndjson()`, `sqlite_scan()`
- SQLite queries require DuckDB sqlite extension (auto-installed)

### Clipboard Paste JSON Detection

- `-P` now auto-detects JSON vs CSV content from clipboard
- Tabular JSON (arrays/NDJSON) converted to CSV via DuckDB
- Non-tabular JSON (nested objects) gracefully falls back to CSV parsing

### Parallel Row Counting

- Files > 10 MB use rayon parallel chunk processing for `-r` row count
- Each thread reads its chunk in 1 MB sub-buffers (no OOM for huge files)
- Dual-path scanning handles quoted newlines correctly across chunk boundaries

### Piped Stdin Detection

- `lazycsv file.csv` now detects when stdin is piped and exits with helpful error
- Previously only `lazycsv` (no file arg) detected piped stdin
- Prevents TUI hangs from `cmd | lazycsv file.csv`
