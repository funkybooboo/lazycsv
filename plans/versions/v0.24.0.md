**Features:**

**Nested theme schema:**
- [x] `[ui]` — global fg/bg/border (paints the entire frame so terminal transparency is fully covered)
- [x] `[table]` — header, zebra rows, cursor, selection, search match, dirty indicator
- [x] `[popup]` — bg/fg/border/title/completion-selected for all modal dialogs
- [x] `[status]` — fg/bg + mode/error/success badges
- [x] `[file_menu]` — directory/highlight/separator/status colors + 8-color preview palette
- [x] `[sql]` — line numbers + diagnostic-error/warning colors

**Renderer wiring:**
- [x] All hardcoded colors and `COLOR_*` constants in `src/ui/modal.rs` removed; every theme-aware helper now requires `&Theme`
- [x] Base canvas pass paints the entire frame with `[ui].bg`/`[ui].fg` before widget rendering
- [x] Non-zebra rows fill with `[ui].bg` (previously fell through to terminal default — visible as "dark stripes" on light themes)
- [x] Title bar (cell preview), horizontal rule, status bar, all popup frames now obey theme
- [x] Help popup, file menu, SQL editor (completion + history), formula completion, file operation prompt, stats overlay, context menu, magnifier — all use the themed `popup_block(theme, …)` helper

**11 example theme presets shipped under `themes/`:**
- [x] Gruvbox Dark / Light
- [x] Dracula
- [x] Nord
- [x] Catppuccin Mocha / Macchiato / Frappé / Latte
- [x] Solarized Dark / Light
- [x] Tokyo Night
- [x] Each preset uses authentic palette hex codes from upstream
- [x] List-highlight colors tuned to subtle surface tones (not saturated accents) on Dracula, all Catppuccin flavors, and Tokyo Night

**Hot-reload:**
- [x] `ConfigWatcher` (already present from v0.9.0) detects theme file changes; status bar shows "Config reloaded"

**Documentation:**
- [x] `docs/themes.md` — complete schema reference with every key, defaults, and example palettes
- [x] `docs/configuration.md` — updated with new section layout
- [x] `themes/README.md` — install instructions + author credits

**Implementation:**
- `src/config/mod.rs` — restructured `Theme` into nested groups (`UiTheme`, `TableTheme`, `PopupTheme`, `StatusTheme`, `FileMenuTheme`, `SqlTheme`); each with its own `Default` impl
- `src/config/toml_parsing.rs` — nested `[ui]`/`[table]`/`[popup]`/`[status]`/`[file_menu]`/`[sql]` sections; warnings include section-qualified field names (`table.cursor_bg` etc.); `file_menu.preview_cols` validated as exactly 8 entries
- `src/ui/modal.rs` — rewritten: deleted `COLOR_*` constants, dropped no-arg style fns, added `popup_block(theme, title)`, `popup_bg_style(theme)`, `popup_text_style(theme)`
- `src/ui/mod.rs` — base-canvas paint at top of `render()`
- `src/ui/table.rs` — non-zebra row fallback uses `theme.ui.bg`; title bar + horizontal rule themed
- `src/ui/{help,file_manager,sql_editor,magnifier,status_bar,stats_overlay}.rs` — every popup/widget threaded through `&Theme`; ~100 hardcoded color references migrated
- `tests/ui_rendering_tests.rs` — updated to construct `Theme { table: TableTheme { … }, ..Default::default() }` and call new helper signatures
- Hard break: removed legacy flat `[theme]` schema (no backwards-compat shim)

**Bench fix (incidental):**
- [x] `benches/sql.rs` — repaired pre-existing breakage (`load_csv_into_sqlite` → `load_csv_into_duckdb`, `rusqlite::Connection` → `duckdb::Connection`)

**Tests (50 config + UI rendering):**
- `src/config/mod.rs` test suite — 50 tests covering nested-section parse, partial overrides, invalid-color warnings (qualified by section), merge semantics, watcher mtime detection
- `tests/ui_rendering_tests.rs` — verifies cursor/selection/search/zebra styles render at runtime against custom `Theme` literals
- All existing UI tests pass after migration
