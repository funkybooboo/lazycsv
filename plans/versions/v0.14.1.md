**Major optimizations already completed in prior versions:**

- **Lazy mmap storage (v0.24.0):** 250M row files open in ~4s with minimal RAM via memory-mapped I/O
- **Buffered I/O indexing (v0.24.0):** 7x faster CSV indexing on macOS
- **DuckDB migration (v0.25.0):** 20x faster SQL queries (88s → ~4s for 50M row GROUP BY)
- **COPY + lazy mmap pattern (v0.25.0):** Query results written to temp CSV via DuckDB COPY, loaded as lazy mmap — keeps RAM at ~2-3GB instead of 30GB+
- **drop_all_tables() (v0.25.0):** Free DuckDB memory after results exported
- **Parallel sort with rayon (v0.24.0):** Fast sorting with sort_order indirection
- **Fast memchr row counting (v0.24.0):** Optimized row counting for large files
- **Raw byte CSV write (v0.24.0):** Fast sorted lazy file output
- **Lazy document clone skip (v0.25.0):** Eliminated 4-minute hang from materializing mmap rows

No further profiling needed at this time.
