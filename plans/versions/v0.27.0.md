## Summary

New CLI commands: `-h` (print headers), `-t` (column statistics via DuckDB), `-D` (dedup with PK columns, `--keep-first`, `--allow-nulls`, `--ignore-case`, `--report-only`). Added `-o` output file support to `-t`, `-h`, `-r`/`-c`, `-s`. Per-command `--help` system (e.g., `-q --help`, `-D --help`) with command-specific examples; `-o` and dedup sub-flags hidden from main help. Changed help flag from `-h` to `--help` only (freeing `-h` for headers). Fixed file save targeting wrong file when opened with a relative path in a multi-file directory (canonicalize path comparison). Renamed `load_csv_*_into_sqlite` to `load_csv_*_into_duckdb`.

## Features

### New CLI Commands

- **`-h, --headers`** - Print header row values for CSV files
  - Works with files, directories, and piped stdin
  - Supports `-o` for file output

- **`-t, --stats`** - Print per-column statistics (CSV format)
  - Output: col_name, data_type, min, max, min_len, max_len, mean, stddev, median, mode, cardinality
  - Powered by DuckDB aggregation queries
  - Pipeable into `-q` for further analysis
  - Supports `-o` for file output

- **`-D, --dedup`** - Deduplicate rows with optional PK columns
  - `-D` (all columns) or `-D=Name,Age` (specific PK)
  - Column names or 1-based indexes
  - `--keep-first` - Keep first occurrence instead of last
  - `--allow-nulls` - Allow all-NULL PK rows (errors by default)
  - `--ignore-case` - Case-insensitive VARCHAR comparison
  - `--report-only` - Report duplicates with row numbers and counts
  - Supports `-o` for file output

### Per-Command Help System

- `--help` with any command flag shows command-specific help
  - e.g., `-q --help`, `-D --help`, `-t --help`, `-s --help`
- Works even when the command flag requires a value (`-q --help` no longer errors)
- Each command's help shows usage, examples, and supported options
- `-o` and dedup sub-flags hidden from main `--help`

### Extended `-o` Support

- Added `-o` output file support to: `-t`, `-h`, `-r`/`-c`, `-s`
- Previously only supported by `-q`, `-x`, `-S`
- Hidden from main help; shown in per-command help

## Bug Fixes

- **File save targeting wrong file** - When opening a file with a relative path (e.g., `lazycsv sample.csv`) in a directory with multiple CSV files, `:w`/`:wq` could save to the wrong file. Root cause: path comparison between CLI arg and directory scan results failed due to relative vs absolute paths. Fix: canonicalize both paths before comparing.

## Refactoring

- Renamed `load_csv_*_into_sqlite` to `load_csv_*_into_duckdb` (4 functions across 3 files)
- Made `duckdb_get_string` and `load_csv_file_into_duckdb` public for reuse
- Centralized output writer helper (`output_writer`, `report_output_file`)
- Moved all command help text to `cli.rs` constants for single-source-of-truth
