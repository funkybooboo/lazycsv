## Summary

New CLI commands: `-h` (print headers), `-t` (column statistics via DuckDB), `-D` (dedup with PK columns, `--keep-first`, `--allow-nulls`, `--ignore-case`, `--report-only`). Added `-o` output file support to `-t`, `-h`, `-r`/`-c`, `-s`. Per-command `--help` system (e.g., `-q --help`, `-D --help`) with command-specific examples; `-o` and dedup sub-flags hidden from main help. Changed help flag from `-h` to `--help` only (freeing `-h` for headers). TUI editing improvements: 1-based row numbering (Excel-compatible), `r` to replace cell, Tab/Enter/arrow keys stay in Insert mode for seamless data entry, horizontal scroll in edit buffer to keep cursor visible, `cw` cell copy (to internal + system clipboard) with smart `p` paste. Fixed file save targeting wrong file when opened with a relative path. Formula engine updated for 1-based cell references (A1 = header row). Renamed `load_csv_*_into_sqlite` to `load_csv_*_into_duckdb`.

## Features

### New CLI Commands

- **`-h, --headers`** - Print header row values for CSV files
  - Works with files, directories, and piped stdin
  - Supports `-o` for file output

- **`-t, --stats`** - Print per-column statistics (CSV format)
  - Output: col_name, data_type, min, max, min_len, max_len, mean, stddev, median, mode, cardinality
  - Powered by DuckDB aggregation queries
  - Pipeable into `-q` for further analysis
  - Supports `-o` for file output

- **`-D, --dedup`** - Deduplicate rows with optional PK columns
  - `-D` (all columns) or `-D=Name,Age` (specific PK)
  - Column names or 1-based indexes
  - `--keep-first` - Keep first occurrence instead of last
  - `--allow-nulls` - Allow all-NULL PK rows (errors by default)
  - `--ignore-case` - Case-insensitive VARCHAR comparison
  - `--report-only` - Report duplicates with row numbers and counts
  - Supports `-o` for file output

### Per-Command Help System

- `--help` with any command flag shows command-specific help
  - e.g., `-q --help`, `-D --help`, `-t --help`, `-s --help`
- Works even when the command flag requires a value (`-q --help` no longer errors)
- Each command's help shows usage, examples, and supported options
- `-o` and dedup sub-flags hidden from main `--help`

### Extended `-o` Support

- Added `-o` output file support to: `-t`, `-h`, `-r`/`-c`, `-s`
- Previously only supported by `-q`, `-x`, `-S`
- Hidden from main help; shown in per-command help

### TUI Editing Improvements

- **1-based row numbering** - Gutter now shows row 1 as header (Excel-compatible)
  - Formula engine updated: A1 = header row, A2 = first data row
  - All formula unit and integration tests updated

- **`r` key** - Replace cell (clear + enter Insert mode), same as `s`

- **Insert mode navigation** - Stay in Insert mode while navigating
  - **Tab** - commit, move right, stay in Insert mode
  - **Shift+Tab** - commit, move left, stay in Insert mode
  - **Enter** - commit, move down, stay in Insert mode
  - **Up/Down arrows** - commit, move up/down, stay in Insert mode
  - **Shift+Left/Right arrows** - commit, move left/right cell, stay in Insert mode
  - **Tab on last column** - inserts new row, moves to first column
  - **Enter on last row** - inserts new row below

- **Edit buffer horizontal scroll** - Long cell content scrolls to keep cursor visible within column width

- **Cell copy/paste** (`cw` / `p`)
  - `cw` copies current cell value to internal clipboard + system clipboard (pbcopy/xclip)
  - `p` is smart: if last yank was a cell (`cw`), pastes into current cell; if rows (`yy`/`dd`), pastes rows below
  - Cell paste is undoable

## Bug Fixes

- **File save targeting wrong file** - When opening a file with a relative path (e.g., `lazycsv sample.csv`) in a directory with multiple CSV files, `:w`/`:wq` could save to the wrong file. Root cause: path comparison between CLI arg and directory scan results failed due to relative vs absolute paths. Fix: canonicalize both paths before comparing.

## Refactoring

- Renamed `load_csv_*_into_sqlite` to `load_csv_*_into_duckdb` (4 functions across 3 files)
- Made `duckdb_get_string` and `load_csv_file_into_duckdb` public for reuse
- Centralized output writer helper (`output_writer`, `report_output_file`)
- Moved all command help text to `cli.rs` constants for single-source-of-truth
