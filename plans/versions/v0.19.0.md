**Features:**

**Column Width:**
- [x] :width A 20 - Set column A width to 20 characters
- [x] :width B auto - Auto-size column B
- [x] :width * auto - Auto-size all columns
- [x] Manual resize with keybindings (+/- keys)
- [x] Per-file column width memory (session)
- [x] Dynamic visible columns based on terminal width (removed hardcoded 10-column limit)

**Column Pinning:**
- [x] :pin A,B / :freeze A,B - Pin columns (always visible on left during horizontal scroll)
- [x] :pin 1,2 / :freeze 1,2 - Pin rows (always visible at top during vertical scroll)
- [x] :unpin / :unfreeze - Unpin all columns and rows
- [x] Visual indicator: cyan + underline on pinned column letters and row numbers
- [x] Pinned columns rendered before scrollable columns with reduced scrollable width
- [x] Pinned rows rendered above scrollable rows in separate layout area
- [x] Per-file pinned state preserved across file switches

**Column Metadata:**
- [x] :type A number - Mark column A as numeric
- [x] :type B date - Mark column B as date
- [x] :type C boolean - Mark column C as boolean
- [x] :type A - Show current column type
- [x] :type A none - Clear column type
- [x] Type validation on edit (rejects invalid values, stays in insert mode)
- [x] Type-aware sorting via :sort (uses ColumnType::compare for typed columns)
- [x] Type indicators in column header: # (number), D (date), ? (boolean)
- [x] Date validation supports YYYY-MM-DD and MM/DD/YYYY formats
- [x] Per-file column types preserved across file switches
