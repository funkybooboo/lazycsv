**Features:**

**Macro Recording:**
- [x] `qa` — Start recording macro into register `a`
- [x] `q` — Stop recording
- [x] `@a` — Replay macro from register `a`
- [x] `@@` — Replay last-played macro
- [x] Multiple registers (a–z, 26 total)
- [x] Replay depth guard (prevents `@a` calling itself indefinitely)
- [x] Per-macro length cap (10,000 keys) to prevent runaway recordings

**Command History:**
- [x] `:history` — Lists most recent 10 entries in the status bar
- [x] Up/Down arrows in command mode walk through history; typed text restored after passing the newest entry
- [x] Typing after a recall invalidates navigation (vim-like)
- [x] Persistent across sessions at `~/.config/lazycsv/command_history` (one entry per line)
- [x] Configurable `[defaults] command_history_limit` (default 50, 0 disables)
- [x] Dedup: re-running an existing command moves it to the front instead of duplicating

**Implementation:**
- `src/macros/mod.rs` (new) — `MacroState` (registers, recording target, current buffer, last-played, replay depth) plus `is_valid_register`
- `src/config/command_history.rs` (new) — `load_command_history` / `save_command_history` mirroring `sql_history`
- `src/app/mod.rs` — `MacroState` wired into `App`; `command_history` + `command_history_index` + `command_history_pending` fields; `replay_macro()` helper; recording hook in `App::handle_key` runs *before* dispatch and is suppressed during replay
- `src/input/actions.rs` — added `PendingCommand::Q` and `PendingCommand::At`
- `src/input/normal_mode/handler.rs` — `q` toggles recording (stops if active, prompts for register otherwise); `@` opens replay prompt
- `src/input/normal_mode/multi_key.rs` — `q<reg>` starts recording, `@<reg>`/`@@` replays
- `src/input/command_mode/handler.rs` — Up/Down history navigation; pushes successful commands; resets index on entry
- `src/input/command_mode/executor.rs` — `:history` ex command
- `src/input/normal_mode/mode_transitions.rs` — resets history index on each command-mode entry
- `src/main.rs` — loads command history at startup, saves on exit
- `src/config/{mod,toml_parsing}.rs` — `command_history_limit` config option
- `src/ui/status_bar.rs` — pending indicator shows `q` / `@`
