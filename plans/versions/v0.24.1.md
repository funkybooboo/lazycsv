**Philosophy:**

LazyCSV's keybindings are now data-driven — loaded from a TOML file at startup, hot-reloadable, and shippable as named preset profiles. Default behaviour stays vim-style; nothing broke for existing users who didn't opt in.

The goal was to make LazyCSV approachable to people who don't already know vim, by letting them load a familiar preset like Excel or Emacs.

---

**Features:**

**Keymap schema (`~/.config/lazycsv/keys.toml`):**
- [x] `[normal]`, `[insert]`, `[visual]`, `[command]`, `[search]`, `[magnifier]`, `[file_list]`, `[sql_editor]`, `[file_operation]`, `[global]` sections — one per mode
- [x] Each entry: `<key sequence> = "<action name>"` (e.g. `"j" = "cursor_down"`, `"ctrl+s" = "save"`)
- [x] Multi-key chord support: `"gg" = "goto_first_row"`, `",dd" = "column_delete"`
- [x] Reserved escape sequences: `"<esc>"`, `"<enter>"`, `"<tab>"`, `"<bs>"`, `"<space>"`, `"<f2>"`, `"<arrow_down>"`, etc.
- [x] Modifier syntax: `"ctrl+x"`, `"shift+tab"`, `"alt+enter"`, `"ctrl+shift+s"`
- [x] Setting a key to `""` (empty string) unbinds it
- [x] Optional `[meta] inherit = "vim"` directive — load a preset, then layer user overrides on top

**Action registry:**
- [x] Catalog every dispatchable action as a string identifier (`cursor_left`, `cell_edit`, `quit`, `enter_visual`, `paste_above`, `sql_open_history`, …)
- [x] Single `Action` enum in `src/input/keymap_actions.rs` (199 named actions)
- [x] All current dispatch tables migrated to look up actions by name
- [x] `:keys` ex command lists every action + its current binding (sortable, searchable)
- [x] Validation: warn on unknown actions, malformed key strings, or duplicate bindings (last wins, but report it)

**Shipped preset profiles** under `keymaps/`:
- [x] `vim.toml` — current behaviour (default; loaded if no user file present)
- [x] `emacs.toml` — readline-style: `Ctrl-f`/`Ctrl-b`/`Ctrl-n`/`Ctrl-p` movement, `Ctrl-a`/`Ctrl-e` line-edge, `Ctrl-x s` to save, `M-x` for command mode, no modal switching
- [x] `excel.toml` — arrow keys for navigation, `F2`/`Enter` to edit, `Tab`/`Shift-Tab` to move horizontally and commit, `Ctrl-c`/`Ctrl-v`/`Ctrl-x`, `Ctrl-z`/`Ctrl-y`, `Ctrl-Home`/`Ctrl-End`, no modes
- [x] `modeless.toml` — minimal binding set for users who want plain typing into cells with arrow-key navigation and no command mode

**Hot-reload:**
- [x] `ConfigWatcher` extended to watch `keys.toml` mtime
- [x] On reload: rebuild the dispatch table; status bar shows "Keymap reloaded"
- [x] Bad reload (parse error / unknown action) keeps the old table active and surfaces a warning
